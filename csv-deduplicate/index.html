Remove duplicate rows from CSV and Excel files

Deleting duplicates by hand risks removing the wrong rows or missing some. We remove them by an explicit rule, count them, show their amounts and check that the totals still reconcile.

What you get

  • A clean file with the duplicates removed by a rule that is written down (for example same date, description and amount)
  • A Checks sheet with the number of duplicates removed per file and the amount they represent
  • Dates, amounts and text normalised at the same time, so near-duplicates are recognised
  • Nothing dropped silently: discarded and duplicate rows are counted separately

Example, before and after (synthetic data)

In the demo, three exports contained 3, 2 and 4 repeated rows: 9 duplicates in total, worth 2,671.97 in amount. They were removed by rule and counted per file; the sums of the remaining rows still matched the totals stated in the source files, and the final table has 0 duplicate rows (checked by a second method).

Two rows that look the same are not always real duplicates (two identical payments on the same day can both be genuine). The rule is agreed and written down before removal, and the Checks sheet lets you review it.

Questions

What counts as a duplicate?

We propose a rule based on your columns (for example same date, description and amount) and show it in the preview. You can change it before the full delivery.

How big can the file be?

The Single file price covers up to 2,000 rows or 10 pages. Larger or multiple files fall under Batch or Monthly.

Do I see what was removed?

Yes. Duplicates are counted per file and their amount is shown in the Checks sheet.
