      How it works

      The tool reads each file in the browser, lines up the columns by header name, and stacks the rows one file after the other. The summary shows how many rows each file contributed and the total, so you can reconcile it against your own counts before downloading.

      Questions

      Is my file uploaded anywhere?

      No. Your files are read and processed by your own browser. Nothing is sent to Rinveta or to any server, and no file content or file name is ever recorded. You can switch off your internet connection after the page has loaded and the tool keeps working. The only thing we count is how often each button is used, in aggregate (no cookies, no profiles).

      Which files can I merge?

      CSV files (comma, semicolon, tab or pipe separated; UTF-8 or Windows-1252 encoding is detected automatically for each file) and Excel .xlsx or .xls files. You can mix CSV and Excel in the same merge. For Excel files only the first sheet of each file is used.

      What if the files do not have the same columns?

      With “First row of each file is a header” ticked, columns are matched by header name, ignoring capital letters and extra spaces, so “Email” and “email ” are the same column. A column that exists in only some files is kept and left empty for the files that lack it, and the tool lists those columns so you notice. Untick the header option to match columns by position instead.

      What does the source-file column do?

      It adds a last column called “Source file” with the name of the file each row came from, so you can trace every row back. The file name is written only into your downloaded file; it is never sent anywhere or recorded.

      Does it change my numbers and dates?

      No. Values are not reformatted. In the CSV they stay exactly as written; in Excel, numbers stay numbers and dates stay dates. Rows are copied as they are, in the order of the files you added.

      Does it remove duplicates?

      No, merging only stacks the rows. To drop repeated rows afterwards, use the free duplicates tool on the merged file.

      How big can the files be?

      Files of tens of thousands of rows work fine on a normal computer. Very large files depend on your browser memory. If it struggles, send us a sample.
