Questions

Can you combine files that have different columns?

Yes, when the columns can be mapped to one target table. The mapping is written down in the Notes sheet so you can check it.

What happens to rows you cannot read?

They are counted and listed as discarded, never dropped silently. The Checks sheet shows how many and why.

Can I get the script as well?

Yes. On request you also receive the commented Python script and a short guide, so you can repeat the job yourself.

What kinds of files can't you process?

We do not process bank statements, payslips, health data or ID documents. For the free preview, blank out any personal details before sending.
