Strumento gratuito

Da fattura elettronica XML a Excel

Carica uno o più file di fattura elettronica (XML, P7M firmato o ZIP) e scarica un foglio Excel con la testata di ogni fattura e tutte le righe di dettaglio. Funziona interamente nel tuo browser: i file non vengono caricati su nessun server. Gratis fino a 20 file per volta, senza registrazione.

1. Scegli i file .xml, .p7m o .zip (o trascinali qui; puoi selezionarne più d'uno)

Nessun file scelto. Nulla viene caricato.

2. Controlla e scarica

    L'Excel contiene i fogli «Testata» e «Righe». I CSV usano il punto e virgola e la virgola decimale e si aprono correttamente in Excel in italiano.

    Riservatezza: elaborazione solo nel tuo browser, nessun upload, nessuna analisi del contenuto o dei nomi dei file. Contiamo soltanto, in forma aggregata e senza cookie, quante volte si usano i pulsanti.

    Cos'è l'XML (o P7M) della fattura elettronica

    Ogni fattura elettronica emessa o ricevuta tramite il Sistema di Interscambio è un file XML nel formato FatturaPA: FPR12 per le fatture tra privati, FPA12 per quelle verso la Pubblica Amministrazione. Se è firmata digitalmente il file ha estensione .xml.p7m: l'XML è dentro una busta di firma CAdES. Più file possono viaggiare insieme in un archivio .zip. Aperto con un editor di testo, l'XML è poco leggibile; per questo si usa un foglio di stile o si converte in una tabella.

    Come si converte in Excel con questo strumento

    1. Scegli i fileSeleziona uno o più file .xml, .p7m o .zip (fino a 20 fatture per volta).
    2. Controlla l'anteprimaVedi quante fatture e quante righe sono state lette e gli eventuali file da controllare.
    3. ScaricaExcel con due fogli (Testata e Righe) oppure i due CSV. Confronta i totali con i tuoi prima di usarli.

    Domande frequenti

    I miei file vengono caricati su un server?

    No. I file vengono letti ed elaborati dal tuo browser, sul tuo computer. Non arrivano a Rinveta né ad altri server, e di loro non registriamo né il contenuto né il nome. Dopo aver caricato la pagina puoi anche scollegare internet e lo strumento continua a funzionare. L'unica cosa che contiamo è quante volte viene premuto ogni pulsante, in forma aggregata (nessun cookie, nessun profilo).

    Cos'è un file XML di fattura elettronica?

    È il file nel formato FatturaPA definito dall'Agenzia delle Entrate e usato dal Sistema di Interscambio (SdI): contiene i dati strutturati della fattura (cedente, cessionario, righe, aliquote IVA, scadenze). Il formato si chiama FPA12 per le fatture verso la Pubblica Amministrazione e FPR12 per le fatture tra privati. Il nome del file segue lo schema codice paese + identificativo del trasmittente + progressivo, per esempio IT01234567890_00001.xml.

    Cos'è un file P7M?

    È lo stesso file XML racchiuso in una busta di firma digitale (formato CAdES). Si riconosce dal nome che finisce con .xml.p7m. Per leggerlo non basta rinominarlo: occorre estrarre l'XML dalla busta, ed è quello che fa questo strumento. La firma non viene verificata: viene letto solo il contenuto.

    Come apro un file XML di fattura elettronica?

    Un XML aperto con il blocco note è leggibile solo da chi conosce il tracciato. L'Agenzia delle Entrate pubblica su fatturapa.gov.it i fogli di stile ufficiali (XSLT) che lo mostrano come una fattura normale. Se invece ti serve elaborare i dati in un foglio di calcolo (registrazione, controlli, riepiloghi), puoi convertirlo in Excel con questo strumento.

    Che file posso caricare?

    File .xml (FatturaPA ordinaria, versioni FPA12 e FPR12), file .p7m firmati (anche in formato testo base64) e archivi .zip che contengono più file .xml o .p7m. Puoi selezionare più file insieme. Gli archivi ZIP dentro altri ZIP, le fatture semplificate e i file di notifica dello SdI non sono supportati e vengono segnalati.

    Quanti file posso convertire?

    Fino a 20 file fattura per volta, gratis e senza registrazione. Se ne carichi di più, vengono elaborati i primi 20 e ti viene detto quanti ne restano da ricaricare in un secondo lotto. Un lotto di fatture dentro un solo file XML conta come un file.

    Cosa contiene il file Excel?

    Due fogli. «Testata»: una riga per fattura con file, formato, tipo documento, numero, data, divisa, cedente/prestatore e cessionario/committente (partita IVA, codice fiscale, denominazione), imponibile, IVA, totale documento, scadenze, importo da pagare, modalità di pagamento e causale. «Righe»: una riga per ogni linea di dettaglio con numero linea, codice articolo, descrizione, quantità, unità di misura, prezzo unitario, prezzo totale, aliquota IVA e natura. Le date sono vere date di Excel e gli importi sono numeri, quindi puoi ordinare e sommare.

    Come sono calcolati imponibile, IVA e totale?

    Imponibile e IVA sono la somma dei blocchi di riepilogo IVA (DatiRiepilogo) della fattura. Il totale è quello dichiarato nel documento (ImportoTotaleDocumento) quando c'è; se manca viene calcolato come imponibile più IVA e la colonna «Origine totale» lo dice. Il totale dichiarato può differire da questo calcolo, per esempio con ritenute, bollo, cassa previdenziale o scissione dei pagamenti: in questi casi controlla sul documento.

    Posso scaricare anche un CSV?

    Sì: un CSV per la testata e uno per le righe (un CSV non può contenere più fogli). Usano il punto e virgola come separatore e la virgola decimale, come si aspetta Excel in italiano, e si aprono correttamente con le lettere accentate. Le celle di testo che iniziano con =, +, - o @ vengono precedute da un apice, per evitare che un foglio di calcolo le esegua come formule.

    Cosa non fa questo strumento?

    Non valida la fattura rispetto allo schema ufficiale, non verifica la firma né la validità del certificato, non controlla se la fattura è stata consegnata dallo SdI, non esporta allegati, ritenute, bollo, cassa previdenziale, dati di trasporto e ordini di acquisto in colonne dedicate, e non gestisce fatture semplificate. Il documento valido ai fini di legge resta il file originale.

    Ti serve qualcosa di diverso?

    Un altro layout di colonne, un riepilogo particolare o un formato che qui manca: scrivici in poche righe cosa ti serve, senza allegare fatture reali (contengono dati di terzi). Rispondiamo di solito entro un giorno lavorativo.
