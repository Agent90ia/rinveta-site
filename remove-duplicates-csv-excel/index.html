    How it works

    The tool reads your file in the browser, builds a comparison key from the columns you tick, and keeps the first row for each key. Rows that repeat a key are listed in the “Removed rows” preview, so you can check before downloading. The counts show rows before, rows after and rows removed, so you can reconcile them against your own totals.

    Questions

    Is my file uploaded anywhere?

    No. The file is read and processed by your own browser. Nothing is sent to Rinveta or to any server, and no file content or file name is ever recorded. You can switch off your internet connection after the page has loaded and the tool keeps working. The only thing we count is how often each button is used, in aggregate (no cookies, no profiles).

    Which files can I use?

    CSV files (comma, semicolon, tab or pipe separated; UTF-8 or Windows-1252 encoding is detected automatically) and Excel .xlsx or .xls files. For Excel files with several sheets, choose the sheet to clean.

    How are duplicates decided?

    Two rows are duplicates when they have the same value in every column you tick. By default all columns are compared, so only identical rows are removed. Tick only the key columns (for example email or invoice number) to remove rows that repeat that key even when other columns differ. The first occurrence is kept unless you choose to keep the last one.

    What do the case and spaces options do?

    “Ignore capital letters” treats Rossi and ROSSI as the same value. “Ignore extra spaces” trims the ends and collapses double spaces, so ‘Anna Rossi ’ equals ‘Anna Rossi’. Your data in the downloaded file is never changed: only the comparison ignores them.

    Does it change my numbers and dates?

    No. Values are not reformatted. In the CSV they stay exactly as written; in Excel, numbers stay numbers and dates stay dates. The download is the same rows minus the duplicates, with the header row kept.

    How big a file can it handle?

    Files of tens of thousands of rows work fine on a normal computer. Very large files depend on your browser memory. If it struggles, split the file or send it to us.

    What if my file is messy, or a PDF?

    This tool only removes exact or key-based duplicates. If your data needs more (merging layouts, fixing columns, tables inside a PDF), send one anonymised sample and you get a free preview of the result before you decide.
