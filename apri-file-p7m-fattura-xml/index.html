Cos'è un file P7M

Una fattura elettronica è un file XML nel formato FatturaPA. Quando chi la emette la firma digitalmente, il file diventa .xml.p7m: l'XML originale è racchiuso in una busta di firma di tipo CAdES. Il nome dell'estensione, P7M, indica appunto un messaggio firmato PKCS#7.

Perché un P7M non si apre

Il sistema operativo non sa che farsene: il file non è un documento ma un contenitore. Rinominarlo in .xml non funziona, perché la busta di firma contiene anche dati binari prima e dopo l'XML. Per leggerlo occorre estrarre l'XML dalla busta, e poi interpretarlo, perché anche l'XML è pensato per essere letto da un programma più che da una persona.

Domande frequenti

Come converto un file P7M in PDF?

Un .p7m è una busta di firma digitale: dentro c'è la fattura elettronica in XML. Scegli il file in questa pagina, leggi la fattura e premi «Stampa / salva PDF»: nella finestra di stampa del browser scegli «Salva come PDF». È gratis, senza registrazione né email e senza caricare il file. Il PDF è una copia di lettura: la fattura valida resta il file XML o P7M originale.

Posso aprire un file .pdf.p7m o convertire fatture XML di altri formati?

No. Questa pagina legge solo fatture elettroniche italiane (FatturaPA) in .xml, .p7m o .zip. Un .pdf.p7m è un PDF firmato, non contiene l'XML di una fattura, e non viene aperto qui.

Come apro un file .p7m di una fattura elettronica?

Il .p7m è l'XML della fattura chiuso in una busta di firma digitale. Scegli il file in questa pagina: lo strumento estrae l'XML dalla busta e lo mostra come una fattura, con parti, righe, riepilogo IVA e scadenze. Non serve rinominare il file né installare programmi.

Perché il file P7M non si apre con un doppio clic?

Perché il formato è una busta CAdES (standard di firma digitale) che molti computer non associano a nessun programma, oppure associano a un programma di firma che non sa mostrare la fattura. Il contenuto utile è l'XML nascosto dentro, che a sua volta, aperto con il blocco note, è poco leggibile.

I miei file vengono caricati su un server?

No. I file vengono letti ed elaborati dal tuo browser, sul tuo computer. Non arrivano a Rinveta né ad altri server, e di loro non registriamo né il contenuto né il nome. Contiamo soltanto, in forma aggregata e senza cookie, quante volte vengono premuti i pulsanti.

Questa vista sostituisce la fattura originale o verifica la firma?

No. La firma digitale non viene verificata e il certificato non viene controllato: viene letto solo il contenuto. Il documento valido ai fini di legge resta il file originale (XML o P7M) conservato secondo le regole di conservazione.

Posso stampare o salvare la fattura in PDF?

Sì: il pulsante «Stampa / salva PDF» apre la finestra di stampa del browser, dove puoi scegliere la stampante oppure «Salva come PDF». Il PDF è una copia di lettura, non la fattura originale.

Che file posso aprire?

File .xml (FatturaPA ordinaria, FPA12 e FPR12), file .p7m firmati (anche in base64) e archivi .zip con più file .xml o .p7m, fino a 20 fatture per volta. Le fatture semplificate, i file di notifica dello SdI e gli ZIP dentro altri ZIP non sono supportati e vengono segnalati.

Cosa non viene mostrato?

Ritenute, cassa previdenziale, dati di trasporto, ordini di acquisto, sconti e maggiorazioni di riga e allegati non sono mostrati in sezioni dedicate. Se il totale del documento differisce dalla somma di imponibile e IVA (per esempio per ritenute o bollo) controlla sul documento originale.

Posso portare i dati in Excel?

Sì: lo strumento gratuito «Da fattura elettronica XML a Excel» crea un foglio con la testata di ogni fattura e tutte le righe, anche per più fatture insieme.

Avvertenza: questo strumento è un aiuto tecnico alla lettura e non costituisce consulenza fiscale, contabile o legale. Non verifica la firma né la validità della fattura. Controlla sempre i dati sul documento originale e con il tuo commercialista; l'XML (o il P7M) originale resta il documento valido. Lo strumento è fornito così com'è, senza garanzie.
